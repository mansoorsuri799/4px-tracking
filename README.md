# 4PX Tracking

Official **4PX Tracking** website at [4pxtracking.net](https://4pxtracking.net) — 4PX Express tracking numbers, cross-border packages, and partner-network scans.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Multi-carrier tracking API integration

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Content

- Brand config: `src/lib/siteConfig.ts`
- Markdown pages: `src/content/`
- Blog routes: `src/app/<slug>/page.tsx`
- Public images: `public/` (logo, feature OG, blog covers)

## Note

This is the **official 4PX Tracking** website for package lookups and tracking guides.
