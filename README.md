# Maersk Tracking

Independent Next.js site for **Maersk tracking** at [maersktracking.com](https://maersktracking.com) — container numbers, bills of lading, booking references, and parcels.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Multi-carrier tracking API integration

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Content

- Brand config: `src/lib/siteConfig.ts`
- Markdown pages: `src/content/`
- Blog routes: `src/app/<slug>/page.tsx`
- Public images: `public/` (logo, feature OG, blog covers)
