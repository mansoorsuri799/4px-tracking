# Maersk Container Tracking: Find Your Container by Number

**Maersk container tracking** follows one physical box through terminals, vessels, and inland moves. If you have the ISO container number from a bill of lading, booking annex, or the doors of the box itself, you can see port events and voyage progress without waiting for a phone update.

## What Is a Maersk Container Number?

Container numbers follow the ISO 6346 format: four letters (owner code + category) plus six digits and a check digit. Maersk-owned boxes often use prefixes such as **MAEU**, though cargo on Maersk sailings can also travel in partner or shipper-owned containers with other prefixes.

Always copy the full number, including the check digit. A single transposed character is the most common reason a lookup fails.

## How Maersk Container Tracking Works

1. The empty container is picked up or supplied for stuffing.  
2. The loaded box **gates in** at the origin terminal.  
3. It is **loaded** onto the vessel and the voyage **departs**.  
4. Optional **transshipment** events appear at hub ports.  
5. The vessel **arrives**, cargo is **discharged**, then **gates out** for delivery or depot return.

Each of those steps can generate a tracking event. Between them — especially on long ocean legs — timelines often stay quiet even when the voyage is on schedule.

## How to Track a Maersk Container

### On MaerskTracking.com

1. Open [maersktracking.com](/).  
2. Paste the full container number into the tracker.  
3. Review the latest status, event list, and any origin/destination fields.  

Use this when you want a fast independent check or when partner scans around the same journey are helpful.

### On Maersk.com

1. Visit [Maersk shipment & container tracking](https://www.maersk.com/tracking/).  
2. Select Ocean cargo.  
3. Enter the container number (or switch to B/L / booking if that is all you have).  

Official tools remain the best confirmation for Maersk-operated milestones.

## Container Number vs Bill of Lading

| Question | Use container number | Use B/L or booking |
| --- | --- | --- |
| Where is this specific box? | Yes | Partial — may list several boxes |
| What is on this contract? | No | Yes |
| Early booking before stuffing? | Often no | Yes |
| Split inland deliveries? | Yes — track each ISO | Use as the parent reference |

If your B/L lists four containers, run **Maersk container tracking** four times — or open the B/L view first, then drill into each ISO number. More detail: [Maersk bill of lading tracking](/maersk-bill-of-lading-tracking).

## How to Read Container Milestones

- **Empty / depot events** — equipment supply before cargo load  
- **Gate in full** — accepted at origin terminal  
- **Loaded on vessel** — marine leg begins soon after  
- **Vessel departed / arrived** — schedule reality vs plan  
- **Discharged** — available for pickup subject to holds  
- **Gate out** — left the terminal toward consignee or rail

Demurrage and detention clocks often relate to how long a container stays in terminal or out of the pool. Tracking alone does not calculate fees, but discharge and gate-out timestamps help conversations with your forwarder.

## Common Container Tracking Problems

### Number not found

- Typo or missing check digit  
- Container not yet gated in  
- Wrong carrier selected for a partner box  
- Booking cancelled or rolled to a later vessel  

### Status stuck for days

Ocean quiet time is normal. Worry more when planned arrival has passed with no discharge event, or when a hold message appears. See [Maersk tracking not updating](/maersk-tracking-not-updating).

### Wrong destination showing

Confirm you are viewing the correct ISO number. Sister containers on the same B/L can take different inland paths after discharge.

## Tips for Accurate Container Visibility

- Photograph container doors at stuffing and discharge yards  
- Cross-check ISO numbers against the B/L annex every time cargo is transferred  
- Save vessel name and voyage from the booking for schedule lookups  
- Ask the terminal or forwarder about holds if discharge exists but gate-out never appears  

## Conclusion

**Maersk container tracking** is most powerful when you treat the ISO number as the unit of truth for physical progress. Paste it on [MaerskTracking.com](/), confirm critical events on Maersk’s official tracker, and pair it with B/L tracking when you need the full contractual picture. For the end-to-end method, start with [how to track a Maersk shipment](/how-to-track-maersk-shipment).
